Here are some datasheet for Pixart IAS sensors.
- PAW3805EK: this model can track move on glass. The CJV1 variant use Infra-Red LED (full and brief version), while CJV2 use blue LED (medium version without register table).
- PMW3325: older model (brief version).
- PMW3360: a popular model with high CPI, build-in accumulate burst (full version).
- PMW3389: a high-end gaming sensor with high CPI (brief version).
- PMW3610: a popular model with lower CPI and low-power consumption. Only public available datasheet with all details (full version).
