Here are some datasheet for Pixart IAS sensors.
PMW3325: older model.
PMW3610: a popular model with lower resolution but supper efficient in energy consumption. Only public available datasheet with all details.
PMW3389: a high-end model with high resolution and speed, used in gaming mouse.
PAW3805: this model can track move on glass.  The CJV1 variant use Infra Red LED, while CJV2 use blue LED.
