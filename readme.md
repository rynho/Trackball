Design a wired trackball featuring twist scroll and 3D rotation.
The design mainly borrow from Kensington Orbit, Export, Slimblade Pro, Ploopy, Efog Endgame, and Rotatrix.

Main specifications:
MCU: ESP32-S2 Mini (ESP32-S2FN4R2)
Sensor: Pixart PAW3805EK-CJV1 (x2)
Ball: 57.2mm American billiard ball
Bearing: 3mm silicon nitride (Si₃N₄) (x3)
Button: MX style keyboard switch (x4)

Dimension:
  - Socket: inner 59.6mm, outer 66mm; 180° semi-sphere.
  - Bearing hole: 3.1*1.8mm, 23°S; 0°E(wrist), 120°E, 120°W.
  - Sensor hole: 4.5*8mm(?) 60°S; 60°E, 150°E.
